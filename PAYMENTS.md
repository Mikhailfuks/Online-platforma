# Внутренние виртуальные карты

Кошелёк хранит принадлежащие пользователю карты в таблице `cards`. У каждой карты уникальный 16-значный номер, активность и баланс `Numeric(10, 2)`. При регистрации создаётся первая карта; существующим пользователям без карт она добавляется при инициализации базы.

Каталог курсов использует таблицу `courses`. При инициализации создаётся курс «Полный курс Python» стоимостью 2 990,00 ₽, связанный с существующими учебными модулями. Покупка списывает сумму с выбранной карты, записывает `Enrollment` и создаёт `Receipt` в одной транзакции.

Пополнения и покупки обрабатываются через `Decimal`. Для каждой операции создаётся PDF-квитанция с кириллическим шрифтом DejaVu Sans. PDF-файлы находятся в `instance/receipts`; страница и загрузка квитанции доступны только её владельцу.

Пополнение сначала создаёт ожидающий запрос с шестизначным одноразовым кодом. Баланс изменяется и PDF создаётся только после правильного ввода кода. Код действует 10 минут; новый можно запросить через 30 секунд, максимум пять неверных попыток допускается до запроса нового кода. В браузере с разрешёнными системными уведомлениями код показывается в системном уведомлении; иначе он остаётся видимым на странице подтверждения.

Таблицы карт, курсов, записей на курс и квитанций создаются SQLAlchemy через `init_db()`. Исторические таблицы внутреннего баланса и `OperationNote` сохранены для совместимости со старыми данными и маршрутами.
